# KOKO – Tienda en línea de productos anime

Proyecto académico (Ingeniería de Software, UNIMINUTO). Es el front-end de una
tienda en línea de productos anime: catálogo, registro e inicio de sesión,
pago y perfil de usuario.

## Funcionalidades
- Catálogo de productos con categorías (figuras, humidificadores, pantuflas,
  peluches y ropa) y control de stock
- Registro e inicio de sesión
- Proceso de pago
- Perfil de usuario
- Páginas de inicio y "Quiénes somos"

## Tecnologías
HTML5, CSS3, JavaScript

## Nota
No tiene backend real: los productos, usuarios y stock se simulan con
localStorage en `JS/koko.js`.

## Cómo ejecutarlo
Descarga el repositorio y abre `inicio.html` en el navegador.
